مدیریت کمپین بلک فرایدی اکسین با قیمت‌گذاری روزانه، Snapshot و بازیابی امن قیمت، نمایش Elementor و شورت‌کد.

== Description ==

افزونهٔ مستقل WooCommerce برای محصولات ساده و Variationهای منتخب. برنامهٔ قیمت خطی یا تصاعدی، صف Action Scheduler، پنل فارسی و RTL، ارسال رایگان اختیاری برای Flat Rate انتخاب‌شده و گزارش سفارش‌های منتسب را فراهم می‌کند.

کف قیمت فقط حداقل قیمت اعمال‌شده توسط موتور کمپین است؛ مبلغ نهایی پس از کوپن و تخفیف خارجی تضمین نمی‌شود. افزونه صفحهٔ جدید نمی‌سازد، طراحی موجود را بازنویسی نمی‌کند و به Elementor یا Woodmart وابستگی اجباری ندارد.

این نسخه باید پیش از استفاده در Production روی Staging فروشگاه ارزیابی شود. مستندات فارسی و گزارش تست در پوشهٔ docs قرار دارند.

== Installation ==

1. از دیتابیس و قیمت‌ها پشتیبان بگیرید و WooCommerce را فعال کنید.
2. ZIP را از افزونه‌ها > افزودن > بارگذاری افزونه نصب و فعال کنید.
3. منوی بلک فرایدی اکسین را باز و تنظیمات کمپین را بررسی کنید.
4. محصول و کف معتبر اضافه کنید؛ Cron واقعی و خرید آزمایشی را تأیید کنید.
5. نمایشگر دلخواه را با شورت‌کد یا ویجت Elementor داخل صفحهٔ موجود قرار دهید.

== Frequently Asked Questions ==

= آیا توقف قیمت را بازیابی می‌کند؟ =

خیر. توقف تغییرات آینده را متوقف می‌کند. بازیابی عملیاتی جدا با تأیید مدیر یا در پایان طبیعی کمپین است.

= بدون Elementor کار می‌کند؟ =

بله. شورت‌کدهای exin_bf_products، exin_bf_featured، exin_bf_countdown، exin_bf_categories و exin_bf_status موجودند.

= آیا همهٔ روش‌های ارسال رایگان می‌شوند؟ =

خیر. فقط Flat Rateهای صریحاً انتخاب‌شده در Package واجد شرایط تغییر می‌کنند. حدنصاب از اقلام کمپین، پس از کوپن و بدون مالیات محاسبه می‌شود.

= هنگام حذف، داده پاک می‌شود؟ =

به‌طور پیش‌فرض حفظ می‌شود. پاک‌سازی Opt-in است و با مالکیت قیمت یا Intent حل‌نشده انجام نمی‌شود. پیش از حذف، Restore و Backup را کامل کنید.
