# اتصال Elementor و شورت‌کدها

افزونه به طراحی، قالب یا مسیر خاص صفحه وابسته نیست و محتوای Elementor را بازنویسی نمی‌کند. صفحهٔ دلخواه را خودتان باز کنید و نمایشگرها را داخل طراحی موجود قرار دهید. مثال سایت مقصد `/black-friday/` است.

## بدون Elementor

در بلوک Shortcode وردپرس یا محتوایی که اجرای شورت‌کد را پشتیبانی می‌کند، از موارد زیر استفاده کنید:

```text
[exin_bf_products]
[exin_bf_featured]
[exin_bf_countdown]
[exin_bf_categories]
[exin_bf_status]
```

محصولات و Featured از همان سرویس انتخاب عمومی استفاده می‌کنند. فهرست عمومی فقط محصولات منتخب مجاز را برمی‌گرداند. تنظیم ستون، تعداد، مرتب‌سازی، دسته‌بندی و Pagination از کنترل‌های نمایشگر انجام می‌شود. برای نام دقیق ویژگی‌های شورت‌کد، بخش «کنترل‌های فعلی» پایین راهنما را ببینید؛ دادهٔ مالی داخلی را به ویژگی HTML اضافه نکنید.

## با Elementor

Elementor را نصب و فعال کنید و صفحه را با آن ویرایش کنید. با جست‌وجوی `EXIN` در فهرست ویجت‌های Elementor، موارد زیر را پیدا می‌کنید:

| ویجت | کاربرد |
| --- | --- |
| EXIN BF Products | همهٔ محصولات منتخب قابل نمایش |
| EXIN BF Featured Products | محصولات دارای Featured Flag |
| EXIN BF Countdown | شمارش معکوس معتبر سرور |
| EXIN BF Categories | دسته‌های محصولات منتخب |
| EXIN BF Campaign Status | پیام و وضعیت فعلی کمپین |
| EXIN BF Product Badge | نشان کمپین برای محصول جاری یا انتخابی |

Products و Featured را با تعداد و ستون مناسب موبایل و دسکتاپ تنظیم کنید. با توجه به محصول و قالب، نمایش قیمت و دکمهٔ خرید از Template استاندارد ووکامرس استفاده می‌کند؛ Variation و انتخاب ویژگی‌ها باید با رفتار عادی ووکامرس هماهنگ باشد. این اتصال به Woodmart وابسته نیست؛ CSS اختصاصی قالب را روی Staging بررسی کنید.

## موجودی و کمپین غیرفعال

تنظیم نمایش ناموجود را از پنل کمپین انتخاب کنید. محصول ناموجود نباید موجود نمایش داده شود؛ Backorder تابع ووکامرس است. پیش از شروع، هنگام توقف و پس از پایان، خروجی مطابق سیاست پیام یا خالی مدیریت می‌شود. نبود Elementor بر کار شورت‌کدها اثر ندارد.

## اطلاعات محرمانه و کش

نمایشگر فقط قیمت جاری، تخفیف معتبر جاری، نام، تصویر و موجودی مجاز را منتشر می‌کند. کف، جدول آینده، Snapshot، Audit و تنظیم مالی نباید در HTML، JavaScript یا REST عمومی قرار گیرند. پیش‌نمایش مدیریتی را در صفحهٔ عمومی Embed نکنید.

شمارش معکوس از اختلاف زمان سرور استفاده می‌کند؛ ساعت دستگاه مشتری مرجع نیست. پس از هر تغییر قیمت، صفحهٔ کمپین و صفحهٔ محصول را با کش و بدون کش بررسی کنید. اگر CDN یا کش صفحه HTML قدیمی نگه می‌دارد، مسیر را Bypass یا Purge هدفمند کنید. افزونه ادعای پاک‌سازی همهٔ سرویس‌های کش خارجی ندارد.

## کنترل‌های فعلی

Products و Featured ویژگی‌های زیر را می‌پذیرند:

| ویژگی | پیش‌فرض | مقادیر |
| --- | --- | --- |
| `columns` | 4 | ستون دسکتاپ، ۱ تا ۶ |
| `tablet_columns` | 2 | ستون تبلت، ۱ تا ۴ |
| `mobile_columns` | 1 | ستون موبایل، ۱ تا ۲ |
| `limit` | 12 | محصول در صفحه، ۱ تا ۴۸ |
| `orderby` | `priority` | `priority`، `title`، `newest`، `price`، `price-desc` |
| `category` | 0 | شناسهٔ دستهٔ محصول؛ صفر یعنی همه |
| `show_out_of_stock` | تنظیم کمپین | `1` برای نمایش و `0` برای مخفی‌کردن ناموجود |
| `pagination` | `yes` | `yes` یا `no` |

نمونه:

```text
[exin_bf_products columns="4" tablet_columns="2" mobile_columns="1" limit="12" orderby="priority" pagination="yes"]
[exin_bf_featured columns="3" limit="6" category="25" show_out_of_stock="0" pagination="no"]
```

`category` شناسهٔ عددی است، نه نام یا Slug. لینک‌های صفحه‌بندی از پارامتر `exin_bf_page` و لینک دسته از `exin_bf_category` استفاده می‌کنند. چند فهرست در یک صفحه این پارامترها را مشترک دارند؛ برای نمایش مستقل صفحه‌بندی‌ها، صفحهٔ جدا یا خاموش‌کردن Pagination یکی از فهرست‌ها را در نظر بگیرید. ویجت Badge کنترل `product_id` دارد و در نبود شناسه از محصول جاری صفحه استفاده می‌کند. کنترل ظاهری رنگ تأکید در ویجت‌های Elementor و متغیر CSS `--exin-bf-accent` در دسترس است.
