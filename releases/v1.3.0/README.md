# EXIN Black Friday 1.3.0

بستهٔ نصب‌پذیر: `exin-black-friday-v1.3.0.zip`؛ هش در `SHA256SUMS` و جزئیات در [test-results.json](test-results.json).

افزایشی، کاهشی، چرخشی، شانسی با Seed ثابت، موجی و ترکیبی با انتخاب صریح مدیر فعال می‌شوند. قیمت از Regular و Floor مستقل هر محصول به دست می‌آید؛ Snapshot، Restore، Lock و Scheduler قبلی استفاده می‌شوند. Manual موجود هنگام نصب تبدیل یا دوباره قیمت‌گذاری نمی‌شود.

تست‌های ۱۷ سناریوی محاسبات/زمان‌بندی، ۹ سناریوی قدیمی، ۷ سناریوی واقعی WooCommerce/HPOS و بررسی‌های تکمیلی نوبت/موجودی مشترک/روز آخر/فعال‌سازی پاس شدند. Smoke رابط ۲۷ بررسی در یک Chromium با REST ساختگی بود. WPCS، نحو JS و ZIP تکرارپذیر ۱۰۱فایلی نیز تأیید شدند؛ تست طولانی و CI کامل اجرا نشد.

راهنمای کوتاه و ارتقا: [روش‌های خودکار و حفظ کمپین ۲](../../docs/automatic-v1.3.0.md). ابتدا بکاپ و کپی ایزوله؛ ZIP را جایگزین کنید و افزونه را حذف یا کمپین Manual را دوباره فعال نکنید. روش جدید فقط برای پیش‌نویسی که مدیر صریحاً خودکار می‌کند فعال است.

**آمادگی Production تأیید نشده است.** به Production متصل نشده‌ایم. طراحی و سرویس‌های واقعی مقصد، ظرفیت Flash و کش/درگاه در آن محیط باید جداگانه تأیید شوند. پیش‌نمایش آینده به موجودی/عضویت و نوبت‌های اجراشده وابسته است؛ مرحلهٔ اجراشده قرعه‌کشی مجدد نمی‌شود.
