# EXIN Black Friday 1.2.1 — اصلاح PR شمارهٔ ۴

بستهٔ نهایی: `exin-black-friday-v1.2.1.zip`، همراه Manifest و `SHA256SUMS`.

فقط دو مسیر اصلاح شده‌اند: بررسی مجدد وضعیت/پایان کمپین هنگام ورود محصول، و تطابق صفحه‌بندی SQL با قیمت معتبر، Visibility والد Variation و شناسهٔ صحیح taxonomy. صفحهٔ خارج از بازه تعداد کل را حفظ می‌کند؛ خروجی همچنان شناسه‌محور، محدود و بدون تکرار است.

۴ تست مرتبط با ۶۸ بررسی روی WordPress 7.1.4، WooCommerce 11.3.0، PHP 8.2.35، MariaDB 11.8.6 و HPOS پاس شدند. WPCS دو کلاس و نحو PHP بدون خطاست؛ EXPLAIN استفاده از ایندکس‌ها را نشان داد. ZIP با ۹۹ فایل و ساخت تکرارپذیر تأیید شد. جزئیات: [test-results.json](test-results.json).

Schema و موتور قیمت تغییر نکرده‌اند. راهنمای ارتقای قبلی همچنان معتبر است: [راهنمای ارتقا](../../docs/upgrade-v1.2.0.md). برای جایگزینی نسخهٔ ۱٫۲٫۰ نیز ابتدا بکاپ/کپی ایزوله بگیرید؛ افزونه را حذف و کمپین را دوباره اجرا نکنید.

هیچ اتصال یا تغییری روی Production انجام نشده است. این اصلاح محدود، تأیید آمادگی Production محسوب نمی‌شود؛ محدودیت‌های محیط واقعی نسخهٔ قبل باقی‌اند.
