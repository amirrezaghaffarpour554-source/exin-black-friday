# EXIN Black Friday 1.2.0

بستهٔ قابل نصب برای بررسی: `exin-black-friday-v1.2.0.zip`، همراه `SHA256SUMS` و Manifest. نتیجهٔ بررسی‌ها در [test-results.json](test-results.json) ثبت شده است.

۳۴ سناریوی PHP، ۱۹ بررسی کنترلر واقعی Blocks و ۶ بررسی رابط مدیریت در یک Chromium پاس شدند؛ بررسی تکمیلی نگهداری اعلان نیز پاس شد. WPCS و نحو JavaScript بدون خطا هستند. ZIP با ۹۹ فایل، ریشهٔ واحد و ساخت تکرارپذیر بررسی شد. داده‌ها مصنوعی و HPOS واقعی است.

موتور مرحله‌ای، Restore، اولویت، Retry، سقف مشترک ارسال و پردازش دسته‌ای نسخهٔ قبل استفاده شدند. کف استثنا، سیاست محصول جدید، کوپن، تازه‌سازی سبد، تنظیمات نمایش، اعلان و گزارش/تاریخچه تکمیل شدند. محاسبه و پرداخت کش‌بک خارجی باقی می‌ماند.

**آمادگی Production تأیید نشده است.** قالب و طراحی واقعی، Redis/WP Rocket/Nginx، درگاه، SMS و افزونهٔ کش‌بک مقصد بررسی نشده‌اند. هیچ اتصال یا تغییری روی Production انجام نشده است.

ارتقا: ابتدا بکاپ و کپی ایزوله؛ ZIP را جایگزین کنید و افزونه را حذف نکنید. کمپین فعال را دوباره اجرا نکنید؛ مهاجرت Schema 4 دادهٔ مالی و نسخهٔ کمپین را حفظ می‌کند. سپس قیمت نمونه‌ها، وضعیت صف و صفحهٔ موجود را تطبیق دهید. راهنمای کامل کوتاه: [ارتقا از ۱٫۱٫۰](../../docs/upgrade-v1.2.0.md).
